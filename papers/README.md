# Reference Papers used in the Project

1. ```DormandPrince.pdf```: Official paper published by J.R Dormand and P.J Prince containing there embedded Runga-Kutta 4(5) family of solvers, used for coefficient-tableau reference and implementation details.
2. ```main.pdf```: J. HOND et al. used for problem definition we aimed to solved here, ```../notebooks/analysis.ipynb``` contains reference to this paper with page number for plots and results.
3. ```ode_solver.pdf```: Used as a reference to understand how initial time-step of adaptive solvers are calculated and used (no directly implemented, a custom scheme was used loosely matching SciPy's implementation).
